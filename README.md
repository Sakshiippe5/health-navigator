# 🏥 AI-Powered Personal Health Navigator

A full-stack AI application for medical document analysis and health assistance.

## Tech Stack
- **Backend:** Python, FastAPI, Uvicorn
- **AI/ML:** Google Gemini, Sentence Transformers, LangChain
- **Vector DB:** ChromaDB
- **PDF Processing:** PyMuPDF

## Features
- 📄 Upload and parse medical PDFs
- 🧠 RAG pipeline for document Q&A
- 💬 Chat with memory across sessions
- 🔍 Semantic search using embeddings
